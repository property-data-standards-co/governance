# Sessions

Material for working sessions: question sets, walkthroughs, slide decks.

Each `.md` file renders as a 16:9 deck on the published site. Slides are separated
by a `---` line; the first block is the title slide. Arrow keys navigate, `F` is
fullscreen, `P` prints to PDF for anyone who wants handouts.

Keep the source in markdown rather than in a presentation tool. It diffs, it
reviews, and it can be amended by anyone with an opinion rather than by whoever
owns the file.

## Convention

Name files for the session: `sprint-zero.md`, `tlp-sprint-1.md`. Where a session
has a question set the working group is expected to answer, put the questions in
the deck rather than in a separate document — the point of a question set is that
everyone sees it at once.
